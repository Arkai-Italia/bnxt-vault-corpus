# Tread - SXS Edition Owner's Manual - Finding an Address

# Finding an Address

NOTE:
The order of the steps may change depending on the map data loaded on your device.

1. Select
   Where To.
2. If necessary, select
    to search near a different city or area.
3. Select
   Address.
4. Follow the on-screen instructions to enter address information.
5. Select the address.
