# Tread Owner's Manual - Joining a Group Ride

# Joining a Group Ride

You can join a nearby group ride that was created by another rider.

NOTE:
For some product models, the Group Ride app is located in the apps menu.

1. From the main menu, select
   Group Ride > Join a Group Ride.
2. Select a nearby group ride, and select
   Join.
