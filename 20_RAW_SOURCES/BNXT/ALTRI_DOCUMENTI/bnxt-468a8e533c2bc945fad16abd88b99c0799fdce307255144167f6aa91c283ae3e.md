# Tread - SXS Edition Owner's Manual - Finding Fuel Stations and Prices

# Finding Fuel Stations and Prices

Before you can use this feature, your device must be connected to a supported phone running the
Tread® app
 ([Pairing with Your Smartphone](https://www8.garmin.com/manuals/webhelp/GUID-F0AC3576-CD83-465E-983D-7AD585ADB59E/EN-US/GUID-9983ED7E-888E-4AD6-A449-CBD17B7838C5.html)).

You can find nearby fuel stations and compare fuel prices.

1. Select
   Where To > Fuel Prices.
2. If necessary, select
    > Fuel Type, select a fuel type, and select
   Save.
3. Select a fuel station.
