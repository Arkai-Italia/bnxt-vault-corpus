# Tread Owner's Manual - Disabling Bluetooth Features (iPhone)

# Disabling Bluetooth Features (iPhone)

By default, all compatible
Bluetooth® features are enabled when you pair your phone. You can disable specific
Bluetooth features and remain connected to the other features.

1. Select
    > Wireless Networks.
2. Select an option:
   * To disable all
     Bluetooth features, clear the
     Bluetooth check box.
   * To disable hands-free calling, select the phone name, and clear the
     Phone calls check box.
