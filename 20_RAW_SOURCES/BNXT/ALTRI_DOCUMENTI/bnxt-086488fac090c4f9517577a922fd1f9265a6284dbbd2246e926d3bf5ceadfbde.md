# Tread Owner's Manual - Enabling Maps

# Enabling Maps

You can enable map products installed on your device.

TIP:
To purchase additional map products, go to
[garmin.com/maps](http://www.garmin.com/maps).

1. Select
    > Map Display > myMaps.
2. Select a map.
