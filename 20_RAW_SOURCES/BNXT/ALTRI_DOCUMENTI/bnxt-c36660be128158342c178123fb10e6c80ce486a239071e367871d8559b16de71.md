# Tread Owner's Manual - Exporting Data from BaseCamp with an Apple Computer

# Exporting Data from BaseCamp with an Apple Computer

1. Select an option:
   * To export all
     BaseCamp™ data stored on your computer, select
     My Collection, and select
     File > Export 'My Collection'.
   * To export one or more items or a list, select one or more items or a list, and select
     File > Export Selected User Data.
2. Enter a name.
3. Select a location for the exported file.
4. Select the file format.
5. Select
   Export.
