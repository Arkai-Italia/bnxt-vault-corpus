# Tread Owner's Manual - Placing a Call Using Voice Dial

# Placing a Call Using Voice Dial

1. Select
    > Phone > Voice Dial.
2. Listen for the voice prompt.
3. Say
   Call, and say the contact name, phone number, or location you want to call.
