# Tread Owner's Manual - Rejoining a Recent Group Ride

# Rejoining a Recent Group Ride

You can rejoin any of your ten most-recent group rides.

1. From the main menu, select
   Group Ride > Recent Group Rides.
2. Select a recent group ride, and select
   Join.
