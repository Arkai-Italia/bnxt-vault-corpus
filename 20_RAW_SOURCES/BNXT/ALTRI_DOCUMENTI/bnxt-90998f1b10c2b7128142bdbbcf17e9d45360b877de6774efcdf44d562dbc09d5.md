# Tread Owner's Manual - Avoiding a Road

# Avoiding a Road

1. Select
    > Navigation > Custom Avoidances.
2. If necessary, select
   Add Avoidance.
3. Select
   Add Avoid Road.
4. Select the starting point of the section of road to avoid, and select
   Next.
5. Select the ending point of the road section, and select
   Next.
6. Select
   Done.
