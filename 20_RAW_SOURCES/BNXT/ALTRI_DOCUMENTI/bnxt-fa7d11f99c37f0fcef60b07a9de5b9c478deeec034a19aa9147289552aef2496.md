# Tread Owner's Manual - Editing a Routine

# Editing a Routine

1. From the
   Garmin PowerSwitch™ app, select
    > Routines.
2. Select
    on the routine you want to edit.
3. Select an option:
   * To change the trigger for the routine, select
     When, and select a trigger.
   * To change an action, select
      on the action you want to change, and update the action.
   * To add an action to the routine, select
     Add Action, and enter information about the action.
4. Select
   Save.
