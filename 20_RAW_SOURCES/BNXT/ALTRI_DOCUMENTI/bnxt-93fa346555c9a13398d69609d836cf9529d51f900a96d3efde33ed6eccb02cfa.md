# Saving a Location

1. Search for a location ([Finding a Location by Category](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-B51EA668-A0A9-40CE-90AA-D3C93FFE5842.html)).
2. From the search results, select a location.
3. Select
    > Save.
4. If necessary, enter a name, and select
   Done.
5. Select
   Save.
