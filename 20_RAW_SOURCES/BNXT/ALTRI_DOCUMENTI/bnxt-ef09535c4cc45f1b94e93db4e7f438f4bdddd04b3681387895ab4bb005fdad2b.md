# Tread - SXS Edition Owner's Manual - Recording Tracks with inReach

# Recording Tracks with inReach

You can record your path using the track recorder and
inReach® team tracking simultaneously.

From the main menu, swipe to the left, and select
inReach >  > Tracking Sync.
