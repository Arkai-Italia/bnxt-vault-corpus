# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - LED Light Settings

# LED Light Settings

Select
.

Set Color
:   Sets the color of the LED lights.

Music Sync
:   Syncs the LED lights to music playback.

Speed Sync
:   Syncs the LED lights to the vehicle's speed.

Group Ride Sync
:   Sets the LED lights to display a call sign color during a group ride.
