# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Sending a Text Message

# Sending a Text Message

1. Select
   inReach > Compose.
2. Select
   To:, and add one or more contacts.
3. Select
   Message:, and enter a message.
4. Select
   Send.
