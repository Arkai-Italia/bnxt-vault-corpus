# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Resetting Trip Information

# Resetting Trip Information

1. From the map, select
   Speed.
2. Select a trip information data field.
3. Select
    > Reset Field(s).
4. Select an option:
   * When not navigating a route, select
     Select All to reset every data field except the speedometer, on the first page.
   * Select
     Reset Overall Data to reset Trip A and total data.
   * Select
     Reset Max. Speed to reset the maximum speed.
   * Select
     Reset Trip B to reset the odometer.
