# Tread - SXS Edition Owner's Manual - Adding BaseCamp Data to Garmin Explore

# Adding BaseCamp Data to Garmin Explore

You can export your
BaseCamp™ data files and import them to
Garmin Explore™ for use with your
Tread® - SXS Edition device.

1. Export your data from
   BaseCamp:
   * If you are using an
     Apple® computer, see
     [Exporting Data from BaseCamp with an Apple Computer](https://www8.garmin.com/manuals/webhelp/GUID-F0AC3576-CD83-465E-983D-7AD585ADB59E/EN-US/GUID-AE94243E-5D09-4E9D-9718-1BFB029A3FAD.html).
   * If you are using a PC, see
     [Exporting Data from BaseCamp with a PC](https://www8.garmin.com/manuals/webhelp/GUID-F0AC3576-CD83-465E-983D-7AD585ADB59E/EN-US/GUID-6F8BBA08-011B-49BB-9B84-827FD48E7AA5.html).
2. Import your
   BaseCamp data to the
   Garmin Explore website ([Importing Data to Garmin Explore](https://www8.garmin.com/manuals/webhelp/GUID-F0AC3576-CD83-465E-983D-7AD585ADB59E/EN-US/GUID-EF463D49-447E-420E-904E-683FBA128376.html)).
3. Synchronize your
   Garmin Explore data with your
   Tread - SXS Edition device ([Synchronizing Garmin Explore Account Data](https://www8.garmin.com/manuals/webhelp/GUID-F0AC3576-CD83-465E-983D-7AD585ADB59E/EN-US/GUID-FE6453B3-08C6-4822-B7E1-405BB92DCE34.html)).
