# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Editing a Contact

# Editing a Contact

1. Select
   inReach >  > inReach Contacts.
2. Select a contact.
3. Select an item to edit.
4. Enter the new information.
5. Select
   Save.
