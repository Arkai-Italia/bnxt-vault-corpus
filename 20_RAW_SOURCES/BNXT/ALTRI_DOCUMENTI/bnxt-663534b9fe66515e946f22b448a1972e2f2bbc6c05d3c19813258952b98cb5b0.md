# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Joining a Group Ride

# Joining a Group Ride

You can join a group ride that was created by another rider.

1. From the main menu, select
   Group Ride > Join a Group Ride.
2. Enter the Ride ID, and select
   Done.
   * To join a radio group ride, select the group ride by the name.
   * To join a mobile group ride, select
     Join with Ride ID and enter the ride ID.
