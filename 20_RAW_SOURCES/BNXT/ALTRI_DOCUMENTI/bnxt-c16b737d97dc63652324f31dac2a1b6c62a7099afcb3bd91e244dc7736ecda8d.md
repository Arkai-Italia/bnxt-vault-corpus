# Tread Owner's Manual - Saving Your Recent Track as a Route

# Saving Your Recent Track as a Route

You can save your recent track as a route, which you can navigate later using the route planner ([Navigating to a Saved Route](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-1793DEB5-5BF9-4322-8944-CFB39DD8737C.html)).

1. Select
   Apps > Adventure > TracBack.

   Your recent track appears on the map.
2. Select
    > Save as Route.
3. Enter a name for the route, and select
   Done.
