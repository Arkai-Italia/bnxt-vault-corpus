# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Deleting Custom Avoidances

# Deleting Custom Avoidances

1. Select
    > Navigation > Custom Avoidances > .
2. Select an option:
   * To delete all custom avoidances, select
     Select All > Delete.
   * To delete one custom avoidance, select the avoidance, and select
     Delete.
