# Tread - SXS Edition Owner's Manual - Date and Time Settings

# Date and Time Settings

Select
 > System > Date & Time.

Use network-provided time
:   Automatically sets the time zone based on information from the connected network.

Use network-provided time zone
:   Sets the time zone on your device when
    Use network-provided time is disabled.

Use 24-hour format
:   Enables or disables the 24-hour time format.
