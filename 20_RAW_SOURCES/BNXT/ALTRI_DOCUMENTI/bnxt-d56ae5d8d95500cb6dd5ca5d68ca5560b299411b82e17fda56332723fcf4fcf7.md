# Saving a Phone Number as a Preset

You can save up to three contacts as presets on the dial pad. This allows you to quickly call your home phone number, family members, or frequently called contacts.

1. Select
   Apps > Tools > Phone.
2. If necessary, select
   .
3. Select a preset number, such as
   Preset 1.
4. Select
   OK, then select a contact.
