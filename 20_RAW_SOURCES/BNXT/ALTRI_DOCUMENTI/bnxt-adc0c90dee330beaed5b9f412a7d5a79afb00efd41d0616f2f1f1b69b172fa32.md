# Tread Owner's Manual - Saving Your Recent Track as a Trip

# Saving Your Recent Track as a Trip

You can save your recent track as a trip, which you can navigate later using the trip planner ([Navigating to a Saved Route](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-1793DEB5-5BF9-4322-8944-CFB39DD8737C.html)).

1. Select
   TracBack.

   Your recent track appears on the map.
2. Select
    > Save as Trip.
3. Enter a name, and select
   Done.
