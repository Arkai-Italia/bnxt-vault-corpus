# Tread Owner's Manual - Enabling Adventure Roads and Trails Map Layers

# Enabling Adventure Roads and Trails Map Layers

You can enable or disable map layers that display accessible or inaccessible roads for different types of motor vehicles.

1. Select
    > Map Display > Map Layers >  > Adventure Roads & Trails.
2. Select a road or trail type.
