# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Adjusting the Squelch

# Adjusting the Squelch

You can adjust the squelch and change squelch modes to filter out unwanted noise and interference in your area.

1. From the main menu, select
    > Adventure > Radio.
2. Select an option:
   * To choose a squelch code within the current mode, select
      or
     .
   * To select a squelch mode, select
     Open ([Squelch Modes](https://www8.garmin.com/manuals/webhelp/GUID-157A2412-594F-45D8-A5EE-5A5327DA0914/EN-US/GUID-6ACD49C9-6514-4249-B43D-4540B596AEB6.html)).
