# Tread Owner's Manual - Navigating a Track

# Navigating a Track

You can navigate a saved track using the
Garmin Explore™ app on your device.

1. Select
   Apps > Adventure > Explore > Tracks.
2. Select a track.
3. Select
   Go!.
