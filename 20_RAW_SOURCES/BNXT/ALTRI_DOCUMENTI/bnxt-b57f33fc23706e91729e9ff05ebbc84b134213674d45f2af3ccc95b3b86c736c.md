# Tread - SXS Edition Owner's Manual - Removing a Shortcut

# Removing a Shortcut

1. Select
   Where To >  > Remove Shortcut(s).
2. Select a shortcut to remove.
3. Select the shortcut again to confirm.
4. Select
   Done.
