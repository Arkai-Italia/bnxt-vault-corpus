# Your Route on the Map

As you travel, the device guides you to your destination using voice prompts and information on the map. Instructions for your next turn or exit, or other actions appear across the top of the map.

  
  

|  |  |
| --- | --- |
| Callout number 1 | Next action in the route. Indicates the next turn, exit, or other action and the lane in which you should travel, if available. |
| Callout number 2 | Distance to the next action. |
| Callout number 3 | Name of the street or exit associated with the next action. |
| Callout number 4 | Route highlighted on the map. |
| Callout number 5 | Next action in the route. Arrows on the map indicate the location of upcoming actions. |
| Callout number 6 | Vehicle speed. |
| Callout number 7 | Name of the road on which you are traveling. |
| Callout number 8 | Estimated arrival time.  TIP: You can touch this field to change the information it shows. |
| Callout number 9 | Map tools. Provides tools to show you more information about your route and surroundings. |
| Callout number 10 | Map layers. Allows you to change the map orientation and add topographic and BirdsEye imagery to your map view. |
