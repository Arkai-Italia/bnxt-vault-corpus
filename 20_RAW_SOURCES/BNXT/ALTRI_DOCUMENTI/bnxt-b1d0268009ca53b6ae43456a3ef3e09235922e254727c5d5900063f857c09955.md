# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Enabling or Disabling Bluetooth Features

# Enabling or Disabling Bluetooth Features

You can enable or disable
Bluetooth® features such as phone calls, media audio, and live services for your paired smartphone.

1. Select
    > Wireless Networks > Bluetooth.
2. Select your phone name.
3. Select a feature to enable or disable it.
