# Assigning a Switch to a Control Input

Before you can use control input functions, you must connect a control input to your
Garmin PowerSwitch™ device ([Connecting a Control Input](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-9B593AFB-4DAA-4BA0-8CD3-DEF888B7D323.html)).

You can assign one or more switches to turn on when the
Garmin PowerSwitch device receives a signal from a control input.

1. Select
   .
2. Select your
   Garmin PowerSwitch device.
3. Select a control input.
4. Select one or more switches.
