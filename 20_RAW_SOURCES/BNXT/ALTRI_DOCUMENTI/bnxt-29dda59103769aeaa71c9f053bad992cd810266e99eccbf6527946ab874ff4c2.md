# Tread Owner's Manual - Wi‑Fi Settings

# Wi‑Fi Settings

The wireless network settings allow you to manage
Wi‑Fi® networks.

Select
 > Wireless Networks.

Wi-Fi
:   Enables the
    Wi‑Fi radio.

Saved Networks
:   Allows you to edit or remove saved networks.

Search for Networks
:   Searches for nearby
    Wi‑Fi networks ([Connecting to a Wi‑Fi Network](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-33553B8C-65FF-4D46-AE4D-3643C89F83DD.html)).
