# Tread - SXS Edition Owner's Manual - Saving Your Recent Track as a Route

# Saving Your Recent Track as a Route

You can save your recent track as a route, which you can navigate later using the route planner ([Navigating to a Saved Route](https://www8.garmin.com/manuals/webhelp/GUID-F0AC3576-CD83-465E-983D-7AD585ADB59E/EN-US/GUID-1793DEB5-5BF9-4322-8944-CFB39DD8737C.html)).

1. Select
   TracBack.

   Your recent track appears on the map.
2. Select
    > Save as Route.
3. Enter a name, and select
   Done.
