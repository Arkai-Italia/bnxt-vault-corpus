# Tread - SXS Edition Owner's Manual - Disabling a Custom Avoidance

# Disabling a Custom Avoidance

You can disable a custom avoidance without deleting it.

1. Select
    > Navigation > Custom Avoidances.
2. Select an avoidance.
3. Select
    > Disable.
