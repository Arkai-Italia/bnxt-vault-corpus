# Tread - SXS Edition Owner's Manual - Avoiding an Area

# Avoiding an Area

1. Select
    > Navigation > Custom Avoidances.
2. If necessary, select
   Add Avoidance.
3. Select
   Add Avoid Area.
4. Select the upper-left corner of the area to avoid, and select
   Next.
5. Select the lower-right corner of the area to avoid, and select
   Next.

   The selected area is shaded on the map.
6. Select
   Done.
