# Saving a Waypoint on the Map

1. Select
   View Map.
2. Drag and zoom the map to display the area to search.
3. Select an option:
   * Select a location marker.
   * Select a point, such as a street, intersection, or address location.
4. Select
   .
5. Enter a name, and select
   Save.
