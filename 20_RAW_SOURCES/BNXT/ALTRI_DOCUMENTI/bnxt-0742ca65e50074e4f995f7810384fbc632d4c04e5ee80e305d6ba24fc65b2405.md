# Tread Owner's Manual - inReach Remote

# inReach Remote

The
inReach® remote function allows you to control your
inReach satellite communication device (sold separately) using your
Tread® device. You can send messages, view weather reports, trigger an SOS alert, and more. Go to
[buy.garmin.com](http://buy.garmin.com) to purchase an
inReach device.
