# Bluetooth Settings

Select
 > Wireless Networks.

Bluetooth
:   Enables
    Bluetooth® wireless technology.

Search for Devices
:   Searches for nearby
    Bluetooth devices.

Friendly Name
:   Allows you to enter a friendly name that identifies your device on other devices with
    Bluetooth wireless technology.
