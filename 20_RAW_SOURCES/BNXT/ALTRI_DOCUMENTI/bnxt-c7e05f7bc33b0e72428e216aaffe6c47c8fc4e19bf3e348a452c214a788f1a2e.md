# Tread Owner's Manual - Up Ahead

# Up Ahead

The
Up Ahead tool provides information about upcoming locations along your route or the road on which you are traveling. You can view upcoming points of interest by category, such as restaurants, fuel stations, or rest areas.

You can customize the categories that show in the
Up Ahead tool.
