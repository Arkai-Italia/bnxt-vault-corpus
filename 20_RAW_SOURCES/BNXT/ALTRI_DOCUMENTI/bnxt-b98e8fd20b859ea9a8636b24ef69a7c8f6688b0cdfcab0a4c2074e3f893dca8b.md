# My device does not appear as a portable device on my computer

On
Mac® computers and some
Windows® computers, the device connects using USB mass storage mode. In USB mass storage mode, the device appears as a removable drive or volume, and not as a portable device.
Windows versions prior to
Windows XP Service Pack 3 use USB mass storage mode.
