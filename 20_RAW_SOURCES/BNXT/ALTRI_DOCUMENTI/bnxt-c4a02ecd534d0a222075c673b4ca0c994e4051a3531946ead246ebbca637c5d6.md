# Tread Owner's Manual - About Memory Cards

# About Memory Cards

You can purchase memory cards from an electronics supplier, or purchase pre-loaded Garmin mapping software ([www.garmin.com](http://www.garmin.com)). Memory cards can be used to store files such as maps and custom POIs.
