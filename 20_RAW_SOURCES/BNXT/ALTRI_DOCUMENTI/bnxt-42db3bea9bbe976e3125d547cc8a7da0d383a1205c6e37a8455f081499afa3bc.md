# Tread Owner's Manual - Driver Assistance Settings

# Driver Assistance Settings

Select
 > Driver Assistance.

Driver Alerts
:   Enables an audible alert for each type of driver alert ([Driver Awareness Features and Alerts](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-85AD37A2-8BDE-4F38-9629-6035CAD0E120.html)).

Proximity Alerts
:   Alerts you when you approach speed cameras or red light cameras.

Route Preview
:   Shows a preview of the major roads in your route when you start navigation.
