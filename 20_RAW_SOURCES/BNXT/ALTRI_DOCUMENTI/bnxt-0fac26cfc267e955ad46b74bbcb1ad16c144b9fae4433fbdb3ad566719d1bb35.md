# Enabling or Disabling Warning Angle Alerts

1. From the main menu, swipe to the left and select
   Pitch and Roll > .
2. Select an option:
   * To enable or disable pitch and roll notifications, select
     Pitch and Roll Notifications.
   * To enable or disable audible alerts, select
     Audible Alerts.
