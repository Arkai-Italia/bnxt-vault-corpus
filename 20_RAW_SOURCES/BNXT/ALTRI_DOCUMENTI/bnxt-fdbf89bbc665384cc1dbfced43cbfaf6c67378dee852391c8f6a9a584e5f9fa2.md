# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Viewing Weather Near a Different City

# Viewing Weather Near a Different City

1. Select
    > Navigation > Weather > Current Location.
2. Select an option:
   * To view weather for a favorite city, select a city in the list.
   * To add a favorite city, select
     Add City, and enter a city name.
