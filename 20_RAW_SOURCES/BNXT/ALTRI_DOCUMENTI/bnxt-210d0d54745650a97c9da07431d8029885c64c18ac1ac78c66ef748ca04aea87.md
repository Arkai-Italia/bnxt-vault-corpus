# Saving Your Recent Track as a Route

You can save your recent track as a route, which you can navigate later using the route planner ([Navigating to a Saved Route](https://www8.garmin.com/manuals/webhelp/GUID-157A2412-594F-45D8-A5EE-5A5327DA0914/EN-US/GUID-BA76112B-92B1-4BF4-8328-E3D6332644A4.html#GUID-1793DEB5-5BF9-4322-8944-CFB39DD8737C)).

1. Select
   TracBack.

   Your recent track appears on the map.
2. Select
    > Save as Route.
3. Enter a name, and select
   Done.
