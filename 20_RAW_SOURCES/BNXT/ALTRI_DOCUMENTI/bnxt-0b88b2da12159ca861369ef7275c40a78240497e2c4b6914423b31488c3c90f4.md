# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Adjusting the Screen Brightness

# Adjusting the Screen Brightness

You can adjust the brightness manually, using either the notification panel or the settings menu.

1. Select an option:
   * Swipe down twice from the top of the screen to expand the quick settings in the notification panel.
   * Select
      > Device > Display > Brightness level.
2. Use the slider bar to adjust the brightness.
