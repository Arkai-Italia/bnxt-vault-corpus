# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Exporting Data from BaseCamp with a PC

# Exporting Data from BaseCamp with a PC

1. Select an option:
   * To export all
     BaseCamp™ data stored on your computer, select
     My Collection, and select
     File > Export > Export 'My Collection'.
   * To export one or more items or a list, select one or more items or a list, and select
     File > Export > Export Selection.
2. Enter a name, select a location for the exported file, select the file format, and select
   Save.
