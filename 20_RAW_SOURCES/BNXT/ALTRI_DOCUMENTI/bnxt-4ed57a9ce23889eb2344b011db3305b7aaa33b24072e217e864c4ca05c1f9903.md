# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Deleting a Saved Location

# Deleting a Saved Location

NOTE:
Deleted locations cannot be recovered.

1. Select
   Where To > Waypoints.
2. Select
    > Delete.
3. Select the box next to the saved locations to delete, and select
   Delete.
