# Placing a Call

1. Select
    > Tools > Phone.
2. Select an option:
   * To dial a number, select
     , enter the phone number, and select
     .
   * To view numbers of recent, missed, or recently dialed or received calls, select
     , select a log, and select a number to dial it.
   * To call a contact from your phone book, select
     , and select a contact.
