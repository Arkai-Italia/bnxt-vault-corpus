# Tread Owner's Manual - Adding a Shortcut

# Adding a Shortcut

You can add shortcuts to the Where To? menu. A shortcut can point to a location, a category, or a search tool.

The Where To? menu can contain up to 36 shortcut icons.

1. Select
   Search > Add Shortcut.
2. Select an item.
