# Tread - SXS Edition Owner's Manual - Finding Tripadvisor Points of Interest

# Finding Tripadvisor Points of Interest

1. Select
   Where To > Tripadvisor.
2. Select a category.

   A list of nearby
   Tripadvisor® points of interest for the category appears.
3. Select
   Sort Results to sort the search results by distance or popularity (optional).
