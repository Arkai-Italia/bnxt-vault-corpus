# Tread Owner's Manual - Disabling Bluetooth Features (Android)

# Disabling Bluetooth Features (Android)

By default, all compatible
Bluetooth® features are enabled when you pair your phone. You can disable specific
Bluetooth features and remain connected to the other features.

1. Select
    > Wireless Networks.
2. Select an option:
   * To disable all
     Bluetooth features, clear the
     Bluetooth check box.
   * To disable only hands-free calling, select the phone name and clear the
     Phone calls check box.
