# Tread Owner's Manual - Enabling or Disabling Bluetooth Features for Your Headset

# Enabling or Disabling Bluetooth Features for Your Headset

By default, all compatible
Bluetooth® features are enabled when you pair your headset. You can enable or disable certain features.

1. Select
    > Wireless Networks.
2. Select the headset name.
3. Select an option:
   * To disconnect the headset, clear the
     Headset check box.
   * To disable audio from streaming media, clear the
     Media Audio check box.
