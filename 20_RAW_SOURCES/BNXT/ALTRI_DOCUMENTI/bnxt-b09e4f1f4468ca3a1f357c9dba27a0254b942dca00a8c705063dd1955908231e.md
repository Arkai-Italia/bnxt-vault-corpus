# Selecting a Preset

NOTE:
For some product models, the Radio app is located in the apps menu.

1. From the main menu, select
   Apps > Adventure > Radio.
2. Select an option:
   * To move through the available presets, select
      or
     .
   * To select a preset from the menu, select
     Presets.
