# Tread Owner's Manual - Finding Tripadvisor Points of Interest

# Finding Tripadvisor Points of Interest

1. Select
   Where To > Tripadvisor.
2. Select a category.
3. If necessary, select a subcategory.

   A list of nearby
   Tripadvisor® points of interest for the category appears.
4. Select
   Sort Results to filter the displayed points of interest by distance or popularity (optional).
5. Select
   , and enter a search term (optional).
