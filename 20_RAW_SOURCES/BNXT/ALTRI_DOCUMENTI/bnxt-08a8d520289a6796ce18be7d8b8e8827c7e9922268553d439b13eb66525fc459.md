# Tread - SXS Edition Owner's Manual - Messages

# Messages

Your
Tread® SXS Edition device sends and receives text messages using the
Iridium® satellite network.
 You can send messages to an SMS phone number, an email address, or another device that uses
inReach® technology. Each message you send includes your location details where allowed.
