# Tread Owner's Manual - Data Management

# Data Management

The device has a memory card slot for additional data storage.

NOTE:
The device is compatible with
Windows® 7 and newer, and
Mac® OS 10.7 and newer.
Apple® computers may require additional third-party software to read and write files.
