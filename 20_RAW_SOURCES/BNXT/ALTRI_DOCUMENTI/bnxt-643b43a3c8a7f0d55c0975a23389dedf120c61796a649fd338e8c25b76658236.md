# Tread Owner's Manual - Viewing the Public Lands Map Key

# Viewing the Public Lands Map Key

Public lands are color-coded on the map to show who owns a specific plot of land. For example, you can see if a plot of land is privately owned or if it is part of a national park. You must enable the public lands map layer to use this feature
 ([Customizing the Map Layers](GUID-7F6C0A18-0F20-45F2-9A20-69B83A64A527.html)).

You can view the legend for these colors on the device.

Select
 > Map Display > Map Layers >  > Public Lands.
