## Pagina 4

Overview of operation


     Both the Dual Sport and Dual Sport VRL share the same functions. The primary
      difference is that the VRL has a Thumb Switch and can be connected to the
      motorcycle's 12 volt battery, which is needed to power the display backlighting
      which is inside the VRL.

     There are two basic modes - Edit mode and Ride mode.

       Edit mode is used to setup wheel circumference, setup Clock, setup Automatic
       Calibration, view and zero trip distance, and to view full distance. Once the
      motorcycle moves .01 miles it is in Ride mode and Edit mode cannot be
      accessed.

     Ride mode has these primary displays:
       * Distance
       * Current Speed
       * Clock time (if enabled in Edit)

     Ride mode also allows access to Peak Speed, which is the highest Speed
     reached during a ride.

  Functions

       * Distance display

       * Current Speed display

       * Peak Speed capture

       * Clock display (if enabled)

       * Edit mode for the following:
                * Wheel size setting
                * Clock display On/Off
                * Automatic calibration On/Off
                * Trip distance - how far you rode since it was last zeroed
                * Full distance - total mileage on the instrument

       * Clock display can be hidden from the Run mode display rotation.

       * Clock (if enabled) runs while the instrument is Shut OFF.

       * Automatic Calibration can adjust the wheel circumference to match the layout
       bike.

       * Full time sensor indicator
