# Tread Owner's Manual - Adjusting the Squelch

# Adjusting the Squelch

You can adjust the squelch and change between CTCSS, DCS, and Open squelch modes to improve audio quality and avoid radio interference in your area.

1. From the main menu, select
   Radio.
2. Select an option:
   * To choose a squelch code within the current mode, select
      or
     .
   * To adjust the squelch mode, select
     Open.
