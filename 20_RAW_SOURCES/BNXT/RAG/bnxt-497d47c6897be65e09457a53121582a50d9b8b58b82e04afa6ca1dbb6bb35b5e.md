**The Best, Made Better!**

The Rallye MAX 2™ is the next step in a thirty year evolution. Already selected for use by the top factory teams like KTM, Husqvarna, Yamaha, and Sherco.

**No More Batteries**

Using an innovative internal backup power supply, the Rallye MAX 2™ can run for up to 7 Dakar-length stages without any external power.

**Better Impact Resistance**

Refinements in the construction offer a substantial increase in frontal LCD impact protection.

**Industry-Leading Display**

We designed a custom LCD with a 180° vertical viewing angle and ultra-sharp contrast. The Rallye MAX-G™ display has super-large digits. We also added 11 helpful on-screen icons to make operation more simple.

**Easy Upgrade**

The Rallye MAX 2™ is a drop-in replacement. Mounting dimensions, cable connections, and accessories are compatible with most rally installations. Overall dimensions are 100mm x 50mm x 24mm.

**Included**:

* Rallye MAX 2™ computer
* New style 3-button remote thumb switch
* Sensor cable with bracket
* Magnet and mounting accessories
* Power cable
* Instruction manual

* OdoQuick™ feature eliminates mode changes to check odometer while in a speed zone
