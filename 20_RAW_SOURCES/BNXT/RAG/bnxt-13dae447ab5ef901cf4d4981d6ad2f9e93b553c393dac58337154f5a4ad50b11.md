# Tread Owner's Manual - Finding and Saving Locations

# Finding and Saving Locations

The maps loaded in your device contain locations, such as restaurants, hotels, auto services, and detailed street information. The
Where To menu helps you find your destination by providing several methods to browse, search, and save this information.

From the main menu, select
**Where To**.

* To quickly search all locations on your device, select
  Search ([Finding a Location Using the Search Bar](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-B23F6873-1D88-489F-9FFC-2932A09C7F73.html)).
* To find an address, select
  Address.
* To browse or search pre-loaded points of interest by category, select
  Categories ([Finding a Location by Category](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-B51EA668-A0A9-40CE-90AA-D3C93FFE5842.html)).
* To search near a different city or area, select
   next to the current search area
   ([Changing the Search Area](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-AEBC9185-86D3-4033-8EAE-B21B7E6DE349.html)).
* To view and edit your saved locations, select
  Waypoints ([Saving Locations](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-D45AB8F1-C349-4AED-A370-72A898B9B18B.html)).
* To view locations you have recently selected from the search results, select
  Recent ([Viewing Recently Found Locations](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-815A4314-20F5-4828-9995-4C361A4B62C2.html)).
* To browse and search
  Tripadvisor® traveler ratings, select
  Tripadvisor ([Finding Tripadvisor Points of Interest](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-D5EA2DE3-FCD8-4C0B-BE47-4515C281CAEC.html)).
* To find national parks and explore park maps, select
  National Parks ([Finding National Parks](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-CE274BA0-D4B4-4C64-886A-C5E1BA0FB903.html)).
* To navigate to specific geographic coordinates, select
  Coordinates ([Finding a Location Using Coordinates](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-84EFF2ED-9C1C-40BC-B147-C4804B2BE09C.html)).
