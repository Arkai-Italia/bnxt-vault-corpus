# Tread Owner's Manual - Wire Gauge Guide

# Wire Gauge Guide

If necessary, you can use longer cables for your installation.

NOTE:
If you are using aluminum or tinned wire, you should use a wire two gauges larger than the gauge listed below to compensate for a potential voltage drop due to the wire material.

* Use 16 AWG (1.31 mm2) for speaker wires.
* Use 20 AWG (0.52 mm2) for LED wires.
