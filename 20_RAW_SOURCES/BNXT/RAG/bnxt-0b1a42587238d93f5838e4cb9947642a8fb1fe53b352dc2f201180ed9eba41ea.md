# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Adding a Location to Your Route

# Adding a Location to Your Route

Before you can add a location to your route, you must be navigating a route ([Starting a Route](https://www8.garmin.com/manuals/webhelp/GUID-157A2412-594F-45D8-A5EE-5A5327DA0914/EN-US/GUID-8A6627F6-AB1E-4DDE-9CB3-193224CAEDB9.html)).

You can add locations to the middle or end of your route. For example, you can add a fuel station as the next destination in your route.

TIP:
To create complex routes with multiple destinations or scheduled stops, you can use the route planner to plan, schedule, and save a route ([Planning a Route](https://www8.garmin.com/manuals/webhelp/GUID-157A2412-594F-45D8-A5EE-5A5327DA0914/EN-US/GUID-BA76112B-92B1-4BF4-8328-E3D6332644A4.html#GUID-84374EC5-29FE-43E3-9BBB-8BBC26F4BBC2)).

1. From the map, select
    > Where To.
2. Search for a location.
3. Select a location.
4. Select
   Go!.
5. Select an option:
   * To add the location as the next destination in your route, select
     Add as Next Stop.
   * To add the location to the end of your route, select
     Add as Last Stop.
   * To add the location and edit the order of destinations in your route, select
     Add to Active Route.

The device re-calculates the route to include the added location and guides you to the destinations in order.
