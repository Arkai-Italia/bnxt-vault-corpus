# Tread Owner's Manual - Planning a Route

# Planning a Route

A route can include many locations, and it must include at least a starting location and one destination. The starting location is the location from which you plan to start your route. If you start navigating the route from a different location, the device gives you the option to route to your starting location first. For a round trip, the starting location and final destination can be the same.

1. Select
   Apps > Navigation > Route Planner > Create Route.
2. If necessary, select a calculation mode.

   NOTE:
   The
   Turn-by-Turn mode is selected by default.
3. Select an option to choose a location for your starting point:
   * Select a location on the map.
   * Select , and search for a location ([Finding a Location Using the Search Bar](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-B23F6873-1D88-489F-9FFC-2932A09C7F73.html)).
4. Repeat step 3 to add more locations.

   NOTE:
   The last location you add is the destination.
5. After you have added all the necessary locations, select
   .
