# Tread Owner's Manual - Status Bar Icons

# Status Bar Icons

The status bar is located at the top of the main menu. The status bar icons display information about features on the device. You can select some icons to change settings or view additional information.

|  |  |
| --- | --- |
| GPS signal status bars | GPS signal status. Hold to view GPS accuracy and acquired satellite information  ([Viewing GPS Signal Status](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-43A143D2-CDFB-40C3-802A-21416A8CEEE4.html)). |
| Bluetooth symbol | Bluetooth® technology status. Select to view the Bluetooth settings ([Bluetooth Settings](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-18037E97-801B-44AB-9906-E4C358C08C3D.html)). |
| Wi-fi signal status | Wi-fi signal strength. Select to change the wi-fi settings ([Wi‑Fi Settings](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-24B32D0A-3601-4054-BC65-3D04F5BAAA31.html)). |
| Phone | Connected to hands-free calling. Select to place a phone call ([Hands-Free Calling](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-465D8A7D-F6AB-490A-ACC6-B226888F1D6E.html)). |
| Vehicle profile | Active vehicle profile. Select to view the vehicle profile settings. |
| Time of day | Current time. Select to set the time ([Setting the Time](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-76083F08-00BD-41F3-9531-3414E8E1B2B9.html)). |
| Battery charge status | Battery charge level. |
| Tread app connection status | Tread™ app connection status ([Pairing Your Phone and Headset](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-883143FA-E7E4-4F4A-906A-4FF7FEEBE594.html)). |
| Temperature | Temperature. Select to view the weather forecast ([Viewing the Weather Forecast](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-8856B830-274E-467C-B66D-261FEADE1CE3.html)). |
| Fuel station | Fuel status. Select to view fuel tracking information ([Fuel Tracking](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-5C107F8C-9237-4FA7-98F2-1E4EC6997683.html)). |
