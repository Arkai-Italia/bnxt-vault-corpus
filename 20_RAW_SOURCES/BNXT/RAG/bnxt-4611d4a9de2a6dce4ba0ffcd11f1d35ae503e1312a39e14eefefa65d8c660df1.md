# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Navigating to a Message Location

# Navigating to a Message Location

When you send or receive a message from another device with
inReach® technology, the message may include location information. For these messages, you can navigate to the location from which the message was sent.

1. Select
   inReach, and select a conversation.
2. Select a message with location information, and select
   Go!.
