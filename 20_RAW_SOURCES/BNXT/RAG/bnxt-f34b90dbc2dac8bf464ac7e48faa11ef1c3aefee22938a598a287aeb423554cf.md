# Taking a Route Using Garmin Adventurous Routing

Your device can calculate adventurous routes that prefer curvy roads, hills, and fewer highways. This feature can provide a more enjoyable ride, but it may increase the time or distance to your destination. The
Garmin Adventurous Routing™ feature is not compatible with off-road trails.

NOTE:
This feature is not available on all device models or for all map regions.

1. Select
   Where To > Categories.
2. If necessary, select a subcategory.
3. Select a location.
4. Select
   .
5. Use the slider to increase or decrease the level of adventure of your route.
6. Select
   Go!
