# EasiFit RallyMoto Bluetooth Remote Controller

We developed this “easifit” bluetooth remote controller for use on the bigger adventure bikes where it is difficult to move the left hand control cluster and clutch mounting.

This controller easily fits onto the left hand grip of the bike, quickly and simply using a cable tie. Removal after use is done in seconds.

The Bluetooth controller is provided to allow ease of operation with the RallyMoto Digital Roadbook App.

The Remote Controller is equivilent to the V1 model and has the following 4 functions:

* Trip Increase
* Trip Decrease
* Roadbook Scroll Up
* Roadbook Scroll Down

Continued pressing of the buttons will repeat the function 4 times per second.
