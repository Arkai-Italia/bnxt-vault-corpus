# Tread Owner's Manual - Wiring

# Wiring

When connecting the speakers and LED lights to your stereo or amplifier, observe these considerations.

* You should use the included wire to connect the speakers to the stereo or amplifier. If necessary, you can use a larger gauge of wire
   ( [Wire Gauge Guide](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-B6F64727-84A5-46A0-89F0-D69AF0C02B3E.html)).
* You should make all of the wiring connections using the included heat-shrink crimp connectors. You should plan and select the best connection type for your installation needs.
* You can use this table to identify the polarity of the leads on the speaker.

  | Lead color | Polarity | Use |
  | --- | --- | --- |
  | White | Positive (+) | Speaker |
  | White with a black stripe | Negative (-) | Speaker |
  | Red |  | Red LED |
  | Green |  | Green LED |
  | Blue |  | Blue LED |
  | Black |  | +12V Power |
