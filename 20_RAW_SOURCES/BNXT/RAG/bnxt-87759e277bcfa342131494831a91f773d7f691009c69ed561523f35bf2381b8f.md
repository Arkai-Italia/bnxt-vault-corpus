# Tread - SXS Edition Owner's Manual - Map Settings

# Map Settings

Select  > Map Display.

Map Vehicle Icon
:   Sets the vehicle icon that represents your position on the map.

Driving Map View
:   Sets the perspective used while viewing the map.

Map Detail
:   Sets the level of detail on the map. More detail may cause the map to draw slower.

Waypoint Labels
:   Sets the size of waypoint labels on the map.

Waypoint Decluttering
:   Hides waypoint icons at high map zoom levels.

Range Rings
:   Shows rings on the map, representing distance from you. The distance to the innermost ring
    appears in the bottom left corner of the screen.

    NOTE:
    Range rings are shown only while using the Track Up or North Up map perspective
    ([Changing the Map Perspective](https://www8.garmin.com/manuals/webhelp/GUID-F0AC3576-CD83-465E-983D-7AD585ADB59E/EN-US/GUID-967C4E16-DAAA-48B9-9480-109AE1B69C8A.html#GUID-7714E17E-4BE8-4797-80FE-B707A03409E0)).

Auto Zoom
:   Automatically selects the zoom level for optimal use of your map. When
    disabled, you must zoom in or out manually.

Skip Next Stop Confirmation
:   Sets a confirmation message to appear when skipping a location on your route.

Units
:   Sets the units of measure.

Position Format
:   Sets the format used for geographical position coordinates and the coordinate
    system used by the map
    ([Position Format Settings](https://www8.garmin.com/manuals/webhelp/GUID-F0AC3576-CD83-465E-983D-7AD585ADB59E/EN-US/GUID-866C34F3-ACD3-498B-BAFC-11D1A4C976A0.html#GUID-189584C9-DFBF-4D7C-AEF0-98CB675156EE)).

Map Manager
:   Manages maps installed on the device.

## Position Format Settings

NOTE:
Do not change the position format or the map datum coordinate system unless you are using a map or chart that specifies a different position format.

Select  > Map Display > Position Format.

Coordinate Format
:   Sets the position format for the location information.

Display Format
:   Sets the format in which coordinates will appear on the device.

Datum
:   Sets the coordinate system on which the map is structured.

Map Spheroid
:   Shows the coordinate system the device is using. The default coordinate system is WGS 84.

## Enabling Maps

You can enable map products installed on your device.

TIP:
To purchase additional map products, go to your product page on [garmin.com](http://www.garmin.com).

1. Select  > Map Display > Map Manager > Manage Device
   Maps.
2. Select a map.
