# **A data-gathering and analyses system**

# **IDR Device**

- The IDR device IDR is a small, costeffective, lightweight and durable device, with a two-year lifespan (maintenance free).

- The IDR is a fit and forget device - simply installed in any vehicle cockpit and it’s ready to record high G impacts, doesn’t require any technical installation.

- Data download via Bluetooth connection using the Mobile App

- Each IDR identified by an unique QR code

# **IDR app**

- Available for both iOS and Android systems

- Allows Race Officials to:

   - View the impact data at the scene

   - “Activate Devices”

   - To download the impact data (via Bluetooth), and submit supplementary information such as: vehicle details; impact photographs; exact location of the impact in the circuit/stage

# **Database**

- Interface available in any web browser (google chrome, for example)

- Secure access with username and password

- User to view, filter and view impact reports by date, vehicle class or geolocation.

- Report data can be downloaded as PDF, or impact data can be downloaded as .csv.

# **IDR Purchase process**

- If an ASN is part of the programme:

   - Competitors must buy directly from their ASN, if ASN is in the IDR programme

   - At this moment: DMSB and MSUK

   - <u>TL113</u>

- If an ASN is not part of the programme:

   - Competitors can buy directly in the supplier e-shop

   - FIA price **is £75 (+ shipping)** / around **€85(+ shipping)**

- **IDR DATA**

- Only accident data is recorded – g acceleration

- FIA officials will report and download data for accident reports

- Report to be stored in a secure database with secure access
