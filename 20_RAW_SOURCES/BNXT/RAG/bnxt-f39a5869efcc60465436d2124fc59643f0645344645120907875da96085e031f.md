## Quick start

### Your first run

Quick start — first run

1. Mount Chrono.Use the supplied plastic mount.Fix it securely to the frame, chassis or helmet.The top of the device must face the sky.Full steps in [Where to mount](https://bybtech.it/manual/chrono#mount-where).
2. Switch on and wait for the GPS fix.Press the power button once — the power LED turns solid green.Wait for the run LED to turn solid green. A first fix can take up to 5 minutes.
3. Record.Press the run button once — the run LED blinks slowly while recording.Press it again to stop.
4. Connect to the app.Hold the run button for 2 seconds to enable Wi-Fi — the run LED blinks quickly.Join the Wi-Fi network BYB-Chrono with the default password bybchrono.Open the BYB Chrono app and go to the device page to change settings and download runs.
5. Optional — extend the setup.Pair an external trigger or BLE sensors from the app.Set the lap type, wheel size and other options.Full steps in [Settings reference](https://bybtech.it/manual/chrono#config-settings).

## Mounting

Chrono can be fitted anywhere on a vehicle, or on a helmet. Placement decides how quickly and how accurately it sees satellites.

### Where to mount

Position the device so that its top — the side carrying the button interface and the BYB Chrono logo — faces upward, toward the sky. A clear view of the sky is what gives a fast fix and accurate positioning.

The supplied plastic mount covers most installations on a frame, chassis, handlebar, roll cage or helmet. Alternatively, the three M3 threaded interfaces can be used to build a dedicated custom mounting.

Examples — any position works as long as the top of the device faces the sky.

### Speed sensor magnet

The magnet is only needed when the speed sensor is in use — see [Operating modes](https://bybtech.it/manual/chrono#config-modes).

1. Fit the magnet to the spokes or to the disc with two thin cable ties.
2. Check that the magnet is detected — the speed sensor LED turns green while a magnet passes it.
3. Enter the wheel diameter in the app. See [Wheel size](https://bybtech.it/manual/chrono#config-wheel-size).

## The device

Chrono is an accurate lap timer built around a high-rate multiconstellation GPS module, with an optional speed sensor and external triggers.

### Main features

* High accuracy GPS antenna, 25 Hz update rate.
* Multi-band, multi-constellation GPS module.
* Built-in speed sensor input.
* Compatible with BYB Chrono external triggers.
* BLE heart rate and power meter sensor support.
* Compact, lightweight and waterproof (IP65).
* Wireless connection to the BYB Chrono app for iOS and Android, and to the BYB Telemetry software.

The device can be run in four configurations, from GPS alone to GPS with both a speed sensor and external triggers. They are described in [Operating modes](https://bybtech.it/manual/chrono#config-modes).

### Operating modes

Chrono runs in four configurations. GPS is always active; the speed sensor and the external trigger are each switched on or off in the configuration menu, and the combination is the mode.

| Mode | Speed sensor | External trigger | What it records |
| --- | --- | --- | --- |
| GPS | No | No | Full route and GPS speed |
| GPS + speed sensor | Yes | No | Full route, speed and distance from the speed sensor |
| GPS + external trigger | No | Yes | Full route and trigger timing |
| GPS + speed sensor + external trigger | Yes | Yes | Route, speed and distance from the speed sensor, trigger timing |

GPS alone records the complete route and speed, and is the basis of every other mode. Route data cannot be loaded into the app without a fix, so always wait for one.

Adding the speed sensor gives accurate speed and distance based on wheel rotation. It can improve accuracy where GPS reception is weak, such as under tree cover, and makes distance-based comparison between runs more accurate. Route and distance from GPS are always recorded; the speed sensor adds a second, wheel-based distance.

Adding external triggers gives timing that does not depend on GPS reception quality: each trigger is placed along the track and records the exact moment it is crossed.

* Open lap — at least two triggers are mandatory: one at the start, one at the finish.
* Closed lap — one trigger at the shared start/finish line is enough.
* Any further triggers act as intermediate splits.

The total number of triggers in use must be entered in the app.

Using both together is the most precise and comprehensive mode — speed, distance and timing in one recording.

### Lap type

Open lap
:   The track has a distinct start and a distinct finish; entry and exit points are separate.

Closed lap
:   The track is a loop with a shared start/finish line. The entry and exit laps are automatically excluded from every calculation.

### Trigger ID

The trigger ID is the name that pairs a trigger with the device. It can be customised; the default is Chrono. The trigger itself — its buttons and LEDs, how to connect to it, its own settings and where to place it — is covered in [External trigger](https://bybtech.it/manual/chrono#trigger).

### Wheel size

The wheel size tells the device how far one revolution of the wheel carries the vehicle, so it can turn sensor pulses into speed and distance. It refers to the wheel the built-in speed sensor reads.

Select a standard size from the list, or enter a custom diameter in millimetres.

### BLE sensors

Chrono connects to commercial BLE heart rate monitors and power meters. Each sensor is paired once; its unique ID is then stored in the device for later sessions.

1. Wake the sensor — wear the heart rate strap, or move the power meter.
2. Enable Wi-Fi mode on the device.
3. Open the app and go to the device configuration menu.
4. Tap "Scan heart rate sensor" or "Scan cycling power meter sensor".
5. Wait for pairing to finish — the unique code of the paired sensor is displayed.
6. Set "Heart rate sensor" or "Power meter sensor" to YES before starting a run.

### IMU orientation

The IMU orientation tells the device how it is installed, so that the direction of each axis is known and advanced metrics can be calculated.

Set the X, Y and Z directions to match the way the device sits on the vehicle.

IMU axes — X, Y and Z, and the rotation around each

### Trigger positioning

Where the triggers sit on the track decides the quality of the timing.

* Open lap — place a trigger about 50 m after the start point and about 50 m before the stop point.
* Closed lap — place the trigger at the start/finish line, as far as possible from any intersection.
* Keep intermediate triggers more than 100 m apart.

## Charging the device

Internal rechargeable battery, 5 V 1 A.

### Battery charging

1. Remove the micro USB protective cap.
2. Connect a micro USB cable to the port.
3. Charge from a PC USB port or a phone charger rated 5 V, 1 A.
4. Wait for the charging LED to go out — lit means charging, off means fully charged.
5. Refit the protective cap before the next ride.

## Troubleshooting

Find the symptom, apply the fix. Anything not here: info@bybtech.it.

### The Wi-Fi password is refused

* Try the default password: bybchrono.
* If the password was changed and is lost, factory reset the device by holding the power button for 8 seconds, then connect again with the default password.

### The Wi-Fi connection is unstable

Some phones drop the device network because it offers no internet access.

Disable mobile data, or turn off the option that switches automatically to a network with internet access, while the device is connected.

### The device cannot get a GPS fix

Switch the device on a few minutes before the run and leave it in a steady position with a clear view of the sky — two to ten minutes is usually enough. The run LED turns solid green once a reliable 3D fix is acquired.

### The recorded run has no GPS map

Logging started before a solid fix was acquired. Always wait for the run LED to turn solid green before starting an acquisition — see [The device cannot get a GPS fix](https://bybtech.it/manual/chrono#ts-gps-fix).

### The device is unresponsive

Hold the power button until the device reboots, about 15 seconds.
