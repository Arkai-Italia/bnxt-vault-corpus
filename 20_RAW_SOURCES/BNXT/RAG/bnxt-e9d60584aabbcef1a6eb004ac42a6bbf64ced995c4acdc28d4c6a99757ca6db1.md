# Digital Rally

#### Introducing TowerOne

A digital navigation system built from the ground up to be the most rugged device possible. A complete system that provides a roadbook display and a full set of navigation instruments: odometer, compass, and waypoints.

##### Hardware features:

* Aluminum case, fully sealed.
* -20°C to 65°C operating temperature range.
* Bright 1600 nits display, 13cm x 17cm.
* No touchscreen; all functions accessible through real tactile switches.
* Loud beeper for waypoint and speed zone alerts.
* Compatible with existing remote switches and mounting systems.

##### Software features:

* Supports both PDF and Openrally roadbooks, including 1-push-per-row scrolling and roadbook-to-odometer setting.
* Supports Openrally waypoint files including nonstandard waypoint radii.
* Supports locked files that can restrict copying, early viewing, or manual waypoint opening.
* Routes can be loaded and selected without an internet connection using either USB memory cards or local WiFi.
* Your device and your routes are yours. No external apps or subscriptions are needed to load routes.
