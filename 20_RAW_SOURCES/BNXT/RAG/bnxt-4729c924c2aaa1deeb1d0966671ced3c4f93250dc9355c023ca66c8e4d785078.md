# Tread Owner's Manual - Editing and Saving Your Active Route

# Editing and Saving Your Active Route

If a route is active, you can use the route planner to edit and save it.

1. Select
    > Route Planner > My Active Route.
2. Edit your route using any of the route planner features.

   The route recalculates each time you make a change.
3. Select
   Save to save your route, which you can navigate again later (optional).
