# Downloading BirdsEye Direct Satellite Imagery

Before you can download
BirdsEye direct satellite imagery directly to your device, you must connect to a wireless network ([Connecting to a Wireless Network](https://www8.garmin.com/manuals/webhelp/GUID-157A2412-594F-45D8-A5EE-5A5327DA0914/EN-US/GUID-68D0B0AA-8293-4BB6-A338-22AB76722DE2.html)).

If you have an active Outdoor Maps+ subscription, you must download satellite imagery
using the map manager ([Downloading Outdoor Maps+ Content](https://www8.garmin.com/manuals/webhelp/GUID-157A2412-594F-45D8-A5EE-5A5327DA0914/EN-US/GUID-967C4E16-DAAA-48B9-9480-109AE1B69C8A.html#GUID-EC61168E-703F-4FC6-973C-822C9B13CBD3)).

2. Select Outdoor Maps+ > Download Satellite
   Imagery.

4. Zoom and scroll the map to show
   the area where you want to view satellite imagery.
