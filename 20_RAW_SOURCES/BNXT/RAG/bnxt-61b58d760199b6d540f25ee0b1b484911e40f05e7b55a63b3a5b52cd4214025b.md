# Tread Owner's Manual - Downloading BirdsEye Imagery

# Downloading BirdsEye Imagery

Before you can download
BirdsEye imagery directly to your device, you must connect to a wireless network ([Connecting to a Wi‑Fi Network](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-33553B8C-65FF-4D46-AE4D-3643C89F83DD.html)).

1. Select
    > BirdsEye Direct.
2. Select
   .
3. Select an option:
   * To download
     BirdsEye imagery files for a specific location or area, select
     Location, and select a category.

     NOTE:
     The location defaults to your current location.
   * To select an image quality option, select
     Detail.
   * To define the size of the area to be shown in the downloaded imagery files, select
     Size, and enter a distance from the selected location.
   * To select where to save the downloaded imagery, select
     Save To.
4. Select
   Download.
5. Enter a name for the downloaded imagery and select
   Done.
