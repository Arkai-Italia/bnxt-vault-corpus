# Tread - SXS Edition Owner's Manual - Finding a Location Using Coordinates

# Finding a Location Using Coordinates

You can find a location using latitude and longitude coordinates.

1. Select
   Where To > Coordinates.
2. If necessary, select , and change the coordinate format or datum.
3. Select
   Coordinates.
4. Enter the latitude and longitude coordinates, and select
   Done.
5. Select an option:
   * To save the coordinates as a location, select
     Save.
   * To start a route to the coordinates, select
     Go!.
