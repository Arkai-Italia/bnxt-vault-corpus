# Tread - SXS Edition Owner's Manual - Enabling LED Groups

# Enabling LED Groups

By default, the controls for LED groups RGB 1 and RGB 2 are enabled. Enabling an LED group allows you to use the LED lighting controls for that group. You can enable the LED group for the
Tread® 6.5" XS-LED Tower Speakers or any additional speakers or addressable LEDs after you set up and pair them with your
Tread Audio Box.

   .
2. Select the LED group.
