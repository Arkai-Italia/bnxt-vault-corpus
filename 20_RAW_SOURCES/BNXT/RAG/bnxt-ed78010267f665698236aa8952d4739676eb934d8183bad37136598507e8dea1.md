# Tread Owner's Manual - Routes

# Routes

A route is a path from your current location to one or more destinations.

* For off-road use, you can set the device to calculate point-to-point routes in a straight line ([Straight Line Routes](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-2BDEF66C-8C39-4E99-91E0-A954CF3B83BD.html)).
* The device calculates a recommended route to your destination based on the preferences you set, including the route calculation mode ([Changing the Route Calculation Mode](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-B9E024D7-8317-4401-983C-9D6B6FA08AC6.html)) and avoidances ([Avoiding Delays, Tolls, and Areas](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-2DED9D60-3C7D-44FE-9997-7A0358FE7DB0.html)).
* You can start navigating to your destination quickly using the recommended route, or you can select an alternate route ([Starting a Route](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-8A6627F6-AB1E-4DDE-9CB3-193224CAEDB9.html)).
* If there are specific roads you need to use or avoid, you can customize the route ([Shaping Your Route](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-D5BD0328-31DA-43AF-B860-0CDC11B46497.html)).
* You can add multiple destinations to a route ([Adding a Location to Your Route](https://www8.garmin.com/manuals/webhelp/GUID-16B1D74D-857B-4FFB-8DE2-A0960FE0D090/EN-US/GUID-A55B7087-E78E-4B3D-A2B9-CC2A56997D9A.html)).
