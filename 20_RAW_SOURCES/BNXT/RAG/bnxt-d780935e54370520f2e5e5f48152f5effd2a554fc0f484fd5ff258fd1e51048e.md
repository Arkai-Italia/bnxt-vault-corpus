# 2025 Red Bull Romaniacs Prologue Adventure Ultimate Class Onboard – Yamaha Tenere 700

Published on July 22nd, 2025 by Enduro21 Team

##### Enduro21 is taking on the new Adventure “Ultimate” class at Red Bull Romaniacs 2025, racing against Jonny Walker and Pol Tarres onboard a Yamaha Tenere 700 Rally – the ultimate adventure bike test we’re calling it!

The Adv bike classes –Lite and Ultimate, we’re in Ultimate – had an easier course due to the mixed abilities and the size of the bikes so it was pretty straight forward, just a bit too one line as you’ll see. The prologue for these classes is simply to set a time to establish start order. It was a fun course though, shame about the massive Ducati road block!
