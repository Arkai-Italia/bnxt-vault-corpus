# Tread Owner's Manual - Port Identification

# Port Identification

| Item | Description |
| --- | --- |
| FUSE | Contains the 15 A fuse for the LED outputs. |
| Callout number 1 | Not used. |
| Callout number 2 | Connects the device to the auxiliary in and line/subwoofer out wiring harness. |
| Callout number 3 | Connects the device to the ground terminal wire (GND). |
| Callout number 4 | Connects the device to the +12V terminal wire. |
| Callout number 5 | Connects the device to the AM/FM antenna. |
| Callout number 6 | Connects the device to the speaker wiring harness. |
| Callout number 7 | Connects the device to the LED wiring harness. |
| Callout number 8 | Connects the device to an optional USB accessory. |
