# Tread Owner's Manual - Connecting to a Wireless Network

# Connecting to a Wireless Network

1. Select
    > Wireless Networks > Wi-Fi.
2. If necessary, select the toggle switch to turn on wireless network technology.
3. Select a wireless network.
4. If necessary, enter the encryption key.

The device connects to the wireless network. The device remembers the network information and connects automatically when you return to this location in the future.
