# Tread Owner's Manual - Status Bar Icons

# Status Bar Icons

The status bar is located at the top of the main menu. The status bar icons display information about features on the device. You can select some icons to change settings or view additional information.

|  |  |
| --- | --- |
| Location services status | Location services status. Indicates your location has been established. |
| Bluetooth symbol | Bluetooth® technology status. |
| Wi-fi signal status | Wi‑Fi® signal strength. |
| Vehicle profile | Active vehicle profile. |
| Time of day | Current time. |
| Battery charge status | Battery charge level. |
| Tread app connection status | Tread® app connection status ([Pairing with Your Smartphone](https://www8.garmin.com/manuals/webhelp/GUID-700B8BF2-F8BB-42A2-A617-3CC00CB4CCA0/EN-US/GUID-9983ED7E-888E-4AD6-A449-CBD17B7838C5.html)). |
