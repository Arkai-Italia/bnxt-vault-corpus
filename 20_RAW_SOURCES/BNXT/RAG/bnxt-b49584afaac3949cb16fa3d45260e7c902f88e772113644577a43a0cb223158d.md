# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Broadcasting a Message

# Broadcasting a Message

WARNING

Do not read, send, or reply to any messages while driving, because doing so can cause a distraction that could lead to an accident resulting in serious personal injury or death.

You can broadcast a preset message to the members in your active group ride that are in range of the VHF radio.

1. From the main menu, select
   Group Ride.
2. If necessary, select
   .
3. Select
   Broadcast to Group.
4. Select a preset message, and select
   Send.
