# **MOUNTING INSTRUCTIONS**

## **Install the spring**

### <u>1</u> **<u>Note!</u>**

_Install the spring on the shock absorber before_ _<u>you install the shock absorber on the vehiicle.</u>_

#### **1**

Measure the spring free length (A).

#### **2**

Loosen the lock nut so that you can move the spring platform as far up as needed to install the spring.

#### **3**

Put the shock absorber up-side-down in a vice. lnstall the spring.

#### **4**

Install the spring clip by sliding it over the end piece and the stop washer. See view from above for unlocked orientation.

#### **5**

Turn the spring clip or the end piece 90° and pull it back to the stop washer. See view from above for locked orientation.

### <u>1</u> **<u>Note!</u>**

_If a spring assembly tool is used, the spring can be compressed by pushing on the spring clip and rotate the end piece to reach locked orientation._

#### **6**

Measure the spring length. Adjust the spring preload to the recommended setup data, found in this Mounting Instruction.

### <u>✋</u> **<u>Caution!</u>**

_Tighten the preload lock nut before riding the vehicle._

# **MOUNTING INSTRUCTIONS**

## **Setting preload**

#### **1**

Loosen the preload lock nut. Use a C-spanner.

#### **2**

Turn the spring by hand to the desired position. The spring platform has a grip function, therefore, by turning the spring you will move the spring platform.

#### **3**

Tighten the preload lock nut.

### <u>1</u> **<u>Note!</u>**

_Make sure the spring platform is not rotating when tightening the lock nut._

#### **1**

Put the motorcycle on a work stand so that the rear wheel barely touches the ground.

#### **2**

Refer to the vehicle manual to install the Öhlins shock absorber.

## **Install the Shock Absorber**

### <u>⚠</u> **<u>Warning!</u>**

_We strongly recommend to let an Öhlins dealer install this product._

### <u>⚠</u> **<u>Warning!</u>**

_If you work with a lifted vehicle, make sure that it is safely supported to prevent it from tipping over._

Note: Torque to 40Nm and do not apply Loctite.

Note: When installing this product to a “Factory” model with a KYB shock absorber, use a fastening screw from a standard model with a WP shock absorber to mount the end piece of this product to the motorcycle linkage.”

### <u>1</u> **<u>Note!</u>**

_When you work with this product, see the vehicle service manual for vehicle specific_ _<u>procedures and important data.</u>_

### <u>1</u> **<u>Note!</u>**

_Lower the vehicle so that the suspension is slightly compressed before you tighten the screws._

### <u>1</u> **<u>Note!</u>**

_Before you install this product clean the vehicle._

### <u>✋</u> **<u>Caution!</u>**

_Make sure that you tighten all screws to the correct torque and that nothing fouls or restricts movement of the shock absorber/front fork/ steering damper when the suspension is fully compressed or extended._
