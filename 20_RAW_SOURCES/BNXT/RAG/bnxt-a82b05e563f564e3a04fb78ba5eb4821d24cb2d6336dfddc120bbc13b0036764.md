# Tread Owner's Manual - Music Player

# Music Player

The media player allows your device to control the media currently playing from a media app on your paired phone. You can open the media player at any time by selecting
Media from the main menu.

|  |  |
| --- | --- |
| Callout number 1 | Information about the currently playing media, such as title, artist, album, station, or channel. |
| Callout number 2 | Progress through the current media item. |
| Callout number 3 | Playback controls. The controls change based on the service providing the media. |
| Callout number 4 | Select to hide or shrink the media player. |
