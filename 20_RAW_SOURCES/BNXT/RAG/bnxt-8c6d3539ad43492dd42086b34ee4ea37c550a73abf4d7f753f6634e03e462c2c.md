# Tread Owner's Manual - Avoiding Toll Roads

# Avoiding Toll Roads

Your device can avoid routing you through areas that require tolls, such as toll roads, toll bridges, or congestion areas. The device may still include a toll area in your route if no other reasonable routes are available.

1. Select
    > Navigation.
2. Select an option:

   NOTE:
   The menu changes based on your area and the map data on your device.

   * Select
     Toll Roads.
   * Select
     Tolls and Fees > Toll Roads.
3. Select an option:
   * To be asked each time before routing through a toll area, select
     Always Ask.
   * To always avoid tolls, select
     Avoid.
   * To always allow tolls, select
     Allow.
4. Select
   Save.
