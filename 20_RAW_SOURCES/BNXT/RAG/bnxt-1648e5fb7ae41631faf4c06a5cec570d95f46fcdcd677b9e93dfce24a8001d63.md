# Tread Owner's Manual - Placing a Call

# Placing a Call

1. Select
    > Phone.
2. Select an option:
   * To dial a number, select
     Dial, enter the phone number, and select
     Dial.
   * To view numbers of recent, missed, or recently dialed or received calls, select
     Call History, select a log, select a number, and select
     Call to dial it.
   * To call a contact from your phone book, select
     Phone Book, select a contact, and select
     Call.
   * To call a point of interest location such as a restaurant or attraction, select
     Browse Categories, select a category, select a location, and select
     Call.
