# Tread Owner's Manual - Connecting to a Wi‑Fi Network

# Connecting to a Wi‑Fi Network

The first time you turn on the device, it prompts you to connect to a
Wi‑Fi® network and register your device. You can also connect to a
Wi‑Fi network using the settings menu.

1. Select
    > Wireless Networks.
2. If necessary, select
   Wi-Fi to enable
   Wi‑Fi technology.
3. Select
   Search for Networks.

   The device displays a list of nearby
   Wi‑Fi networks.
4. Select a network.
5. If necessary, enter the password for the network, and select
   Done.

The device connects to the network, and the network is added to the list of saved networks. The device reconnects to this network automatically when it is within range.
