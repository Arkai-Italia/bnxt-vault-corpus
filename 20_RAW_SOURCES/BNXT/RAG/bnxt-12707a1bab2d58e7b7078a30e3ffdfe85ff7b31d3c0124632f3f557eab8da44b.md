# Tread - SXS Edition Owner's Manual - Display Settings

# Display Settings

Select
 > Device > Display.

Brightness level
:   Sets the display brightness level on your device.

Dark theme
:   Enables or disables the dark color theme.

Wallpaper
:   Sets the wallpaper background on your device.

Screen timeout
:   Allows you to set the amount of idle time before your device turns off the display while using battery power.

Font size
:   Increases or decreases the font size on your device.
