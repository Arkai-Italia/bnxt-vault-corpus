# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Route Planner

# Route Planner

You can use the route planner to create and save a route, which you can navigate later. This can be useful for planning a delivery route, a vacation, or a road trip. You can edit a saved route to further customize it, including reordering locations, adding suggested attractions, and adding shaping points.

## Planning a Route

A route can include many stops and shaping points, and it must include at least a starting location and one destination.

1. Select  > Navigation > Route Planner > .
2. Search for or select a location
   on the map to be the starting point for this route.
3. If necessary, select a route calculation mode for the route segment.
4. Select an option:
   * If the next point along your route is a stop, select Stop.
   * If the next point in your route is a shaping point, select Shaping.
5. If necessary, add additional stops or shaping points.

   NOTE:
   The last stop you add is the route destination.
6. If necessary, select
    to rearrange the order of stops and shaping points along the route.
7. After you have finished planning the route, select
   .

## Navigating to a Saved Route

1. Select
    > Navigation > Route Planner.
2. Select a saved route.
3. Select
   Go!.
4. Select the first location to navigate to, and select
   OK.
5. Select
   Start.

   The device calculates a route from your current location to the selected location, and then it guides you to the remaining route destinations in order.
