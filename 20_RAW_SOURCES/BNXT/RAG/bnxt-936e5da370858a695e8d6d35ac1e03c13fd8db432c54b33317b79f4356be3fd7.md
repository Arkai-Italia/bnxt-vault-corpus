# Tread Owner's Manual - Straight Line Routes

# Straight Line Routes

For areas without defined roads or trails, the device guides you to your destination using a straight line route. You can set multiple waypoints to navigate a route through areas without roads.

|  |  |
| --- | --- |
| Callout number 1 | Distance to the destination. |
| Callout number 2 | Route highlighted on the map. |
| Callout number 3 | Vehicle speed. |
| Callout number 4 | Map tools. Provides tools to show you more information about your route and surroundings. |
| Callout number 5 | Map layers. Allows you to change the map orientation and add topographic and BirdsEye imagery to your map view. |
