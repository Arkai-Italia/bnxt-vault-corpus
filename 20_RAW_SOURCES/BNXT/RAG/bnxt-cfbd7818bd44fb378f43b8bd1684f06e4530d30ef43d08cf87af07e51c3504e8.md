# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Speaker Zones

# Speaker Zones

You can group speakers in one area into speaker zones. This enables you to control the audio level of the each zone individually.

Zones 1 and 2 are powered by the on-board amplifier. To use the RCA line output, you must connect an external amplifier.

You can set the balance, tone, and name for each zone, and the fade between zones.
