# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Using the Map

# Using the Map

You can use the map to navigate a route ([Your Route on the Map](https://www8.garmin.com/manuals/webhelp/GUID-157A2412-594F-45D8-A5EE-5A5327DA0914/EN-US/GUID-B80737A7-7EC9-488C-AC8C-AC12B7BF8EB4.html)) or to view a map of your surroundings when no route is active.

1. Select
   View Map.
2. Touch anywhere on the map.
3. Select an option:
   * Drag the map to pan left, right, up, or down.
   * To add or remove map layers such as topographic and BirdsEye imagery, select
     .
   * To zoom in or out, select  or .
   * To switch between North Up, 2-D, and 3-D views, select .
   * To open the route planner, select
      ([Route Planner](https://www8.garmin.com/manuals/webhelp/GUID-157A2412-594F-45D8-A5EE-5A5327DA0914/EN-US/GUID-BA76112B-92B1-4BF4-8328-E3D6332644A4.html#GUID-BA76112B-92B1-4BF4-8328-E3D6332644A4)).
   * To start a route, select a location on the map, and select
     Go! ([Starting a Route by Using the Map](https://www8.garmin.com/manuals/webhelp/GUID-157A2412-594F-45D8-A5EE-5A5327DA0914/EN-US/GUID-0020E6C8-320B-4F07-8C24-54CEB6867385.html)).
