# Tread Owner's Manual - Location Search Results

# Location Search Results

By default, the location search results appear in a list, with the nearest location at the top. You can scroll down to view more results.

|  |  |
| --- | --- |
| Callout number 1 | Select a location to view the option menu. |
| Callout number 2 Information | Select to view detailed information about the selected location. |
| Callout number 3 Parking symbol | Select to find parking areas near the location. |
| Callout number 4 Alternate routes | Select to view alternate routes to the locations. |
| Callout number 5 Adventurous routing | Select to start navigating to the location using Garmin Adventurous Routing™. |
| Callout number 6 Go! | Select to start navigating to the location using the recommended route. |
| Callout number 7 Search results map | Select to view the search results on the map. |
