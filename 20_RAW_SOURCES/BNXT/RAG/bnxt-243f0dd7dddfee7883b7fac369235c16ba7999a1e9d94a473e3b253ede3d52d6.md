# Tread Owner's Manual - Units and Time Settings

# Units and Time Settings

To open the Units and Time settings page, from the main menu, select
 > Units & Time.

Current Time
:   Sets the device time.

Time Format
:   Allows you to select a 12-hour, 24-hour, or UTC display time.

Units
:   Sets the unit of measure used for distances.

Position Format
:   Sets the coordinate format and datum used for geographical coordinates.
