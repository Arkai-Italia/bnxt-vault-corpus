# Tread Owner's Manual - Tread Audio App

# Tread Audio App

Before you can use the controls in the
Tread® Audio app, you must install your
Tread Audio Box and
Tread 6.5" XS-LED Tower Speakers in your vehicle and pair the
Tread Audio Box with the
Tread Audio app.

|  |  |
| --- | --- |
| Callout number 1 | Displays information about the currently playing media, such as title, artist, album, station, or channel. |
| Callout number 2 | Displays progress through the current media item. |
| Callout number 3 | Displays playback controls. The controls change based on the service providing the media. |
| Callout number 4 | Displays the current audio source. Bluetooth symbol indicates the media is being played by another media app on your phone and sent to the device using a Bluetooth® media connection. |
| Callout number 5 | Opens the LED controls. |
| Callout number 6 | Opens the app settings menu. |
| Callout number 7 | Opens the volume zone controls. |
| Callout number 8 | Mutes the audio. |
| Callout number 9 | Increases or decreases the volume. |
