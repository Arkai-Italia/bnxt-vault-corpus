# Tread - SXS Edition Owner's Manual - Assigning Categories to a Saved Location

# Assigning Categories to a Saved Location

You can add custom categories to organize your saved locations.

NOTE:
Categories appear in the saved locations menu after you have saved at least 12 locations.

1. Select
   Where To > Waypoints.
2. Select a location.
3. Select
   .
4. Select
    > Edit > Categories.
5. Enter one or more category names, separated by commas.
6. If necessary, select a suggested category.
7. Select
   Done.
