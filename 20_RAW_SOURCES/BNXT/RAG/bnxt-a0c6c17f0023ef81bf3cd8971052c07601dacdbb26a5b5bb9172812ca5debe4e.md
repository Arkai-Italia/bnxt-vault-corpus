# Tread - SXS Edition Owner's Manual - Traffic Settings

# Traffic Settings

From the main menu, select
 > Traffic.

Traffic
:   Enables the traffic feature.

Current Provider
:   Sets the traffic provider to use for traffic data. The
    Auto option selects the best available traffic data automatically.

Subscriptions
:   Lists the current traffic subscriptions.

Optimize Route
:   Enables the device to use optimized alternate routes automatically or upon request ([Avoiding Traffic Delays on Your Route](https://www8.garmin.com/manuals/webhelp/GUID-F0AC3576-CD83-465E-983D-7AD585ADB59E/EN-US/GUID-A482BB24-F5E9-4B93-A930-68478FC1C14D.html)).

Traffic Alerts
:   Sets the traffic delay severity for which the device displays a traffic alert.
