# RallyMoto EasiFit Bluetooth Controller V2

The  EasiFit V2 Bluetooth controller is easily fitted and removed. Developed for big bikes it attached by cable tie to the left hand grip, so you don’t have to move any controls on the handlebar.

The unit allow sease of operation with the RallyMoto Digital Roadbook App AND Rally Navigator Roadbook Reader, OSMand, DMD2 (4 Button Model), Media Plays such as Spotify etc, TET App

The controller requires a USB power supply.

The V2 controller has 2 open modes for use with the android “keymapper” app.

The keymapper app allows a large number of configurable options for almost any app. The keymapper app listens for the controller output and  converts this to the configured function e.g screen swipes to move maps around or screen presses to use zoom buttons etc within apps.

This allows each user to customise these modes for use with any app of their preference.
