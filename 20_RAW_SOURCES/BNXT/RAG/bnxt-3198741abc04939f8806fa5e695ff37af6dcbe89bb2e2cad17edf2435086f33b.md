# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - inReach Tracking Settings

# inReach Tracking Settings

Select
inReach > .

Tracking Sync
:   Sets the device to use the track recorder and
    inReach® tracking simultaneously.

Auto Track
:   Sets the device to start tracking when you turn on the device.

Send Interval
:   Sets the frequency at which the device records a track point and transmits it over the satellite network when you are moving. If you are on a professional plan, you can specify the interval when you are stationary.
