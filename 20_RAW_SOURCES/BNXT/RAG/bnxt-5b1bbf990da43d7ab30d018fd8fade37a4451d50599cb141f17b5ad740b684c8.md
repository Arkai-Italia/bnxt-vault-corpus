# 2020 AMA Ice Race Grand Championship postponed again

* by [Jim Witters](https://americanmotorcyclist.com/author/jwittersama-cycle-org/)
* January 30, 2020
* 0 Comments
* 2925 Views

## New date to be set for oval ice racing national championship

The American Motorcyclist Association Ice Race Grand Championship event that had been rescheduled for Feb. 1 in Oshkosh, Wis., has been postponed due to poor ice conditions. A new date for the event has yet to be announced.

The canceled event was to feature oval course racing.

The national championship event featuring grand-prix style ice racing is still to take place at Kettle Moraine Lake in Campbellsport, Wis., on Feb. 16.
