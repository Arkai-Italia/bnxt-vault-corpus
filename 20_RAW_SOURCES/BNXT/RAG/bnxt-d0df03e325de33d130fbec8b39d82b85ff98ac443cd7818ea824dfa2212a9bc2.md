# Tread - SXS Edition Owner's Manual - Adding a Location to Your Route

# Adding a Location to Your Route

Before you can add a location to your route, you must be navigating a route ([Starting a Route](https://www8.garmin.com/manuals/webhelp/GUID-F0AC3576-CD83-465E-983D-7AD585ADB59E/EN-US/GUID-8A6627F6-AB1E-4DDE-9CB3-193224CAEDB9.html)).

You can add locations to the middle or end of your route. For example, you can add a fuel station as the next destination in your route.

1. From the map, select
    > Where To.
2. Search for a location ([Finding and Saving Locations](https://www8.garmin.com/manuals/webhelp/GUID-F0AC3576-CD83-465E-983D-7AD585ADB59E/EN-US/GUID-0CAA56CC-20EF-42EE-86F1-C2356C804582.html)).
3. Select a location.
4. Select
   Go!.
5. Select an option:
   * To add the location as the next destination in your route, select
     Add as Next Stop.
   * To add the location to the end of your route, select
     Add as Last Stop.
   * To add the location and edit the order of destinations in your route, select
     Add to Active Route.

The device re-calculates the route to include the added location and guides you to the destinations in order.
