# Tread - Overland Edition Tread XL - Overland Edition Owner's Manual - Radio

# Radio

NOTE:
This feature is not available on all product models.

NOTE:
Before you can use the Radio app, you must install a Group Ride accessory. Go to
[garmin.com](http://www.garmin.com) to purchase a Group Ride accessory.

You can use the Radio app to create radio presets, select a radio channel, and select squelch codes. To use this feature, you must connect the device and the antenna to the Group Ride mount. The
Tread® - Overland Edition device configures radio settings automatically when you join or create a group ride.
