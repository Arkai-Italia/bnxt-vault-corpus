# Tread Owner's Manual - Changing the Map Perspective

# Changing the Map Perspective

1. Select
    > Map Display > Driving Map View.
2. Select an option:
   * Select
     Track Up to display the map in two dimensions (2-D), with your direction of travel at the top.
   * Select
     North Up to display the map in 2-D with north at the top.
   * Select
     3-D to display the map in three dimensions.
   * Select
     Auto Zoom to Group to automatically adjust the zoom level so all riders in a group ride are visible on the map.
3. Select
   Save.
