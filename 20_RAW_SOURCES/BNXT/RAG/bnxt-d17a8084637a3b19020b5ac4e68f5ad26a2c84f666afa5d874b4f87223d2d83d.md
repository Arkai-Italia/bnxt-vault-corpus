# Tread Owner's Manual - Location Search Results

# Location Search Results

The location search results appear in a list, with the nearest location at the top. Each numbered location also appears on the map. You can scroll down to view more results.

|  |  |
| --- | --- |
| Callout number 1 | Select a location to view the option menu. |
| Callout number 2 Information | Select to view detailed information about the location. |
| Callout number 3 Alternate routes | Select to view alternate routes to the location. |
| Callout number 4Adventurous routing | Select to start navigating using Garmin Adventurous Routing™. |
| Callout number 5 Go! | Select to start navigating to the location using the recommended route. |
